== 이름

nftconf - 선언적 nftables 구성과 실시간 대조

== 개요

*nftconf* [_전역_]... _CMD_ [_옵션_]... [_FILE_]...

== 설명

*nftconf* 는 간단한 선언적 설정을 읽어 활성 *nftables*(8) 규칙과 맞춥니다.
각 논리 규칙에는 소유 주석이 있어 *load*/*unload*/*daemon* 이 해당 파일 규칙만 변경합니다.

NAT 는 prerouting/output/postrouting 에 적용되며 *INPUT* 을 열지 않습니다.
호스트 전달 포트는 명시적 *allow incoming*（또는 *whitelist*, 선택 *shield on*）이 필요합니다.

== 명령

*load* _FILE_::
  _FILE_ 을 활성 규칙과 대조합니다. 기본은 문 하나당 nft 규칙 하나입니다.
  *-c, --compact* 는 일치하는 allow/deny 를 nft 집합으로 묶습니다（이전 동작）.

*unload* _FILE_::
  문 전체가 활성 규칙과 일치할 때만 제거합니다. *-f, --force* 는 남은 압축 규칙을 분해하고 가능한 한 많은 원자를 제거합니다（원본이 줄거나 바뀐 경우）.

*status* _FILE_::
  기대와 활성 규칙의 차이를 표시합니다.

*check* _FILE_::
  전개된 nft 규칙을 분석하여 출력합니다（적용하지 않음）.

*show* _FILE_::
  각 문 왼쪽에 너비 8 상태 열: *on*（완전 활성）, *N/M*（부분）,
  *---*（미적재）, *xxx*（구문 오류）.

*daemon* _FILE_::
  _FILE_（및 include）을 inotify 로 감시하고 변경 시 다시 읽습니다.
  기본 pidfile 은 */run/nftconf.pid* 이며 두 번째 인스턴스는 거부됩니다.

*stop*::
  pidfile（*--pid*）로 데몬을 중지합니다.

*convert* _FILE_...::
  모은 *nftables.d/\*.nft*（매크로와 포트 집합）를 씁니다.

*help*::
  사용법을 표시합니다.

== 전역 옵션

*-v, --verbose*::
  디버그 로그（반복 가능）.

*-q, --quiet*::
  오류만.

*-h, --help*::
  도움말 표시.

*--version*::
  버전을 출력하고 종료.

== 충돌 정책

*load*, *daemon*, *convert* 에 적용됩니다.

（기본）::
  기존 nft 설정과 충돌하면 중단.

*-f, --force*::
  충돌하는 활성 규칙을 덮어씀（*load*）.

*-n, --no-clobber*::
  충돌하는 변경을 건너뜀.

*--dry-run*::
  적용하지 않고 동작만 표시.

*load -c/--compact*::
  일치하는 문을 nft 집합으로 묶기.

*unload -f/--force*::
  남은 압축 규칙을 분해하고 일치하는 원자 제거.

== 설정 언어

한 줄에 한 지시문. 빈 줄은 무시. *#* 는 주석（따옴표 안 제외）. NAT 또는 필터 문과 같은 줄의 주석은 소유 태그 뒤의 nft 규칙 comment 로 복사됩니다. 첫 토큰이 지시 이름. 이름과 키워드는 대소문자를 구분하지 않습니다. 문맥은 다음 문맥 지시까지 유지됩니다. 블록 문법은 없습니다.

=== 문맥

*table* _이름_ [_패밀리_]::
  대상 테이블（기본 *nftconf*）. 패밀리 *ip*（기본）, *ip6*, *inet*, *arp*, *bridge*, *netdev*.

*interface* _IFACE_...::
  *iifname* 일치. *address* 가 나올 때까지 해당 NIC 의 IPv4 를 해석. 인터페이스마다 한 규칙.

*address* _ADDR_...::
  목적지 주소 일치（*ip daddr*）. 인터페이스 해석을 덮어씀.

*dest address* / *dest interface*::
  `nat … to PORT` 의 기본 내부/VIP 쪽. *destination* 은 *dest* 의 별칭.

*priority* _이름_|_수_::
  INPUT 훅 우선순위. NAT 훅은 무시.

*shield* *on*|*off*::
  현재 인터페이스/주소 범위의 기본 드롭 INPUT 허용 목록. *on* 만으로는 응용 포트를 열지 않습니다.

*include* _GLOB_::
  파일 포함（포함 파일 기준 상대 경로）. 현재 문맥 사본을 상속.

=== 포트（tcp / udp / sctp / dccp）

포트 프로토콜 뒤에 포트, 닫힌 구간, 또는 목록（공백 및/또는 쉼표）. 하나면 스칼라/범위, 둘 이상이면 nftables 익명 집합.

----
allow incoming tcp 22
allow incoming tcp 8000-8080
allow incoming tcp 80 443 1080 8000-8080
deny incoming tcp 33
allow outgoing ip 10.0.0.0/8 tcp 443
nat tcp 80 443 8000-8080 to 10.0.0.50
----

포트는 0–65535. *HIGH* 는 *LOW* 이상. 선택적 *ADDR:PORT*（또는 *[IPv6]:PORT*）가 목록 접두어. 아니면 *address* / *interface* 가 *ip daddr* 을 제공합니다.

목록은 *allow* / *deny* / *whitelist* / *blacklist* 와 *nat* / *dnat* / *snat* / *masquerade* / *redirect*（*to* 앞）에서 씁니다. *icmp* / *ct* 에는 쓰지 않습니다.

=== NAT 와 필터

*nat* / *dnat* / *snat* _PROTO_ _PORT_... *to* _DEST_, *masquerade*, *redirect*. NAT 는 *INPUT* 을 열지 않습니다.

*allow incoming* / *deny incoming*（별칭 *whitelist* / *blacklist*）는 INPUT. *allow outgoing ip CIDR* [*PROTO* [_PORT_...]] 는 OUTPUT. 프로토콜/포트를 생략하면 해당 CIDR 의 모든 트래픽.

*단일 포트* 가 *범위* 보다 먼저 맞으며, 같은 구체도에서는 *allow* 가 *deny* 보다 앞섭니다.

*shield on* 이면 수신 정책이 실드 체인에 들어갑니다.

*reject … with* 이후는 모두 nftables 로 전달됩니다（*tcp reset* 등）.

자세한 내용은 *guide.md* 와 `info nftconf`.
