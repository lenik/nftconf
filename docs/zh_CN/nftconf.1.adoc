== 名称

nftconf - 声明式 nftables 配置与实时对账

== 语法

*nftconf* [_全局选项_]... _命令_ [_选项_]... [_文件_]...

== 描述

*nftconf* 读取简洁的声明式配置，并与运行中的 *nftables*(8) 规则集对账。
每条逻辑规则带有所有权注释，便于后续 *load*、*unload*、*daemon* 只增删属于该配置文件的规则。

NAT 作用在 prerouting/output/postrouting，*不会* 自动开放 *INPUT*。
需要本机投递的端口须显式 *whitelist*/*accept*（可选 *shield on*）。

== 命令

*load* _文件_::
  将 _文件_ 与活动规则集对账。默认一条 statement 对应一条 nft 规则。
  *-c, --compact* 将匹配的 allow/deny 打包进 nft 集合（旧行为）。

*unload* _文件_::
  仅在整条 statement 完全匹配时移除活动规则。*-f, --force*
  在整体不匹配时拆散残余的打包规则，尽可能多地移除原子。

*status* _文件_::
  显示期望与活动规则之间的差异。

*check* _文件_::
  解析并打印展开后的 nft 规则。

*show* _文件_::
  每条 statement 的状态（*on*、*N/M*、*---*、*xxx*）。

*daemon* _文件_::
  监视 _文件_（及 include），变更时重新加载。
  默认使用 pidfile */run/nftconf.pid*，第二实例会拒绝启动。

*stop*::
  通过 pidfile（*--pid*）停止守护进程。

*convert* _文件_...::
  写出汇总的 *nftables.d/\*.nft*。

*help*::
  显示用法。

== 全局选项

*-v, --verbose*::
  调试日志（可重复）。

*-q, --quiet*::
  仅错误。

*-h, --help*::
  显示帮助。

*--version*::
  输出版本并退出。

== 冲突策略

适用于 *load*、*daemon*、*convert*：

（默认）::
  与现有 nft 设置冲突则中止。

*-f, --force*::
  覆盖冲突的活动规则（*load*）。

*-n, --no-clobber*::
  跳过冲突变更。

*--dry-run*::
  只显示动作，不应用。

*load -c/--compact*::
  将匹配的 statement 打包进 nft 集合。

*unload -f/--force*::
  拆散残余的打包规则并移除匹配的原子。

== 配置语言

配置文件每行一条指令。空行忽略。*#* 起注释（引号内除外）。首个词元为指令名，
指令与关键字不区分大小写。上下文对其后的规则一直有效，直到下一条上下文指令。
没有块语法。

=== 上下文

*table* _名称_ [_族_]::
  目标表（默认 *nftconf*）。族为 *ip*（默认）、*ip6*、*inet*、*arp*、
  *bridge*、*netdev*。

*interface* _网卡_...::
  匹配 *iifname*；并解析这些网卡的 IPv4，直到出现 *address*。每个网卡生成一条规则。

*address* _地址_...::
  目的地址匹配（*ip daddr*），覆盖网卡解析。

*dest address* / *dest interface*::
  `nat … to PORT` 的默认内网/VIP 侧。*destination* 是 *dest* 的别名。

*priority* _名_|_数_::
  INPUT 钩子优先级。NAT 钩子不受此影响。

*shield* *on*|*off*::
  当前网卡/地址作用域的默认丢弃 INPUT 白名单。*on* 本身不会开放应用端口。

*include* _GLOB_::
  包含文件（相对包含者所在目录）；继承当前上下文的副本。

=== 端口（tcp / udp / sctp / dccp）

端口协议之后写：单个端口、闭区间、或列表（空格和/或逗号分隔）。
单项生成为标量或区间；两项及以上生成为 nftables 匿名集合。

----
allow incoming tcp 22
allow incoming tcp 8000-8080
allow incoming tcp 80 443 1080 8000-8080
deny incoming tcp 33
allow outgoing ip 10.0.0.0/8 tcp 443
nat tcp 80 443 8000-8080 to 10.0.0.50
----

端口范围 0–65535；*HIGH* 必须 ≥ *LOW*。可选 *ADDR:PORT*（或 *[IPv6]:PORT*）
作为列表前缀。否则由 *address* / *interface* 提供 *ip daddr*。

列表可用于 *whitelist* / *accept* / *allow* / *drop* / *reject*，以及
*nat* / *dnat* / *snat* / *masquerade* / *redirect*（在 *to* 之前）。
不用于 *icmp* / *ct*。

=== NAT 与过滤

*nat* / *dnat* / *snat* _协议_ _端口_... *to* _目的_，*masquerade*，
*redirect*。NAT *不会* 开放 *INPUT*。

*whitelist* / *allow* 等同 *accept*。*shield on* 时进入盾牌链。
*reject … with* 之后的全部词元交给 nftables（如 *tcp reset*）。

详见 *guide.md* 与 `info nftconf`。
