== Nomo

nftconf - deklara nftables-agordo kun viva kunigo

== Sintakso

*nftconf* [_GLOBAL_]... _CMD_ [_OPTION_]... [_FILE_]...

== Priskribo

*nftconf* legas mallongan deklaran agordon kaj kunigas ĝin kun la viva
*nftables*(8)-reguloj. Ĉiu logika regulo havas posedan komenton.

NAT funkcias ĉe prerouting/output/postrouting kaj *ne* malfermas *INPUT*.
Gastigantaj pordoj bezonas eksplicitan *whitelist*/*accept*.

== Komandoj

*load* _FILE_::
  Reconcile _FILE_ against the live ruleset.

*unload* _FILE_::
  Remove live rules owned by _FILE_.

*status* _FILE_::
  Show drift between desired and live rules.

*check* / *show* _FILE_::
  Parse and print resolved rules (no apply).

*daemon* _FILE_::
  Watch _FILE_ (and includes); reload on change.
  Default pidfile */run/nftconf.pid*; a second instance refuses to start.

*stop*::
  Stop the daemon via the pidfile (*--pid*).

*convert* _FILE_...::
  Write consolidated *nftables.d/\*.nft*.

*help*::
  Show usage.

== Ĝeneralaj opcioj

*-v, --verbose*::
  Debug logging (repeatable).

*-q, --quiet*::
  Errors only.

*-h, --help*::
  Show help.

*--version*::
  Print version and exit.

== Konfliktopolitiko

(default)::
  Abort if existing nft settings conflict.

*-f, --force*::
  Overwrite (load) or remove owned rules anyway (unload).

*-n, --no-clobber*::
  Skip conflicting changes.

*--dry-run*::
  Show actions without applying.

== Agorda lingvo

Unu direktivo en linio. Malplenaj linioj estas ignorataj. *#* komencas
komenton (krom en citiloj). La unua ĵetono estas la direktivo; nomoj kaj
ŝlosilvortoj estas usklec-sendependaj. Kunteksto daŭras ĝis la sekva
kunteksta direktivo.

=== Kunteksto

*table*, *interface*, *address*, *dest address* / *dest interface*,
*priority*, *shield on|off*, *include*.

=== Pordoj (tcp / udp / sctp / dccp)

Post pordohava protokolo: unu pordo, inkluziva intervalo, aŭ listo
(spacetoj kaj/aŭ komoj). Unu ero fariĝas skalaro/intervalo; du aŭ pli
fariĝas anonima nftables-aro.

----
allow incoming tcp 22
allow incoming tcp 8000-8080
allow incoming tcp 80 443 1080 8000-8080
deny incoming tcp 33
allow outgoing ip 10.0.0.0/8 tcp 443
nat tcp 80 443 8000-8080 to 10.0.0.50
----

Pordoj 0–65535; *HIGH* ≥ *LOW*. Laŭvola prefikso *ADDR:PORT* (aŭ
*[IPv6]:PORT*). Alie *address* / *interface* donas *ip daddr*. Listoj
validas por filtrilo kaj NAT (antaŭ *to*), ne por *icmp* / *ct*.

=== NAT kaj filtrilo

*nat* / *dnat* / *snat* _PROTO_ _PORT_... *to* _DEST_, *masquerade*,
*redirect*. NAT ne malfermas *INPUT*.

*whitelist* / *allow* estas kaŝnomoj de *accept*. Kun *shield on* ili
eniru la ŝildan ĉenon. Ĉio post *reject … with* iras al nftables
(*tcp reset*, …).

Vidu *guide.md* kaj `info nftconf`.

== Dosieroj

*/run/nftconf.pid*::
  Default daemon pidfile.

*nftables.d/\*.nft*::
  Default *convert* output directory.

== Elirstato

*0*::
  Success.

*1*::
  Config/conflict/runtime error.

*2*::
  Usage error.
