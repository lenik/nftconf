== Nome

nftconf - configurazione nftables dichiarativa con riconciliazione live

== Sintassi

*nftconf* [_GLOBALE_]... _CMD_ [_OPZIONE_]... [_FILE_]...

== Descrizione

*nftconf* legge un piccolo linguaggio dichiarativo e lo riconcilia con il
ruleset *nftables*(8) attivo. Ogni regola logica ha un commento di proprietà
così *load*, *unload* e *daemon* modificano solo le regole di quel file.

Il NAT agisce su prerouting/output/postrouting e *non* apre *INPUT*.
Le porte consegnate all'host richiedono *allow incoming* (o *whitelist*,
opzionalmente *shield on*).

== Comandi

*load* _FILE_::
  Riconcilia _FILE_ con il ruleset live. Di default un'istruzione diventa
  una regola nft. *-c, --compact* raggruppa gli allow/deny corrispondenti
  in insiemi nft (comportamento precedente).

*unload* _FILE_::
  Rimuove una regola live solo se l'intera istruzione corrisponde.
  *-f, --force* spezza una regola compatta residua e rimuove quanti più
  atomi possibile (sorgente accorciata o modificata).

*status* _FILE_::
  Mostra lo scostamento tra desiderato e live.

*check* _FILE_::
  Analizza e stampa le regole nft risolte (senza applicare).

*show* _FILE_::
  Stampa ogni istruzione con una colonna di stato larghezza 8: *on*
  (completamente live), *N/M* (parziale), *---* (non caricata),
  *xxx* (errore di sintassi).

*daemon* _FILE_::
  Osserva _FILE_ (e gli include) con inotify; ricarica al cambiamento.
  Pidfile predefinito */run/nftconf.pid*; una seconda istanza è rifiutata.

*stop*::
  Ferma il demone tramite il pidfile (*--pid*).

*convert* _FILE_...::
  Scrive *nftables.d/\*.nft* consolidati (define e insiemi di porte).

*help*::
  Mostra l'uso.

== Opzioni globali

*-v, --verbose*::
  Registro di debug (ripetibile).

*-q, --quiet*::
  Solo errori.

*-h, --help*::
  Mostra l'aiuto.

*--version*::
  Stampa la versione ed esce.

== Politica di conflitto

Si applica a *load*, *daemon* e *convert*:

(predefinito)::
  Interrompi se le impostazioni nft esistenti sono in conflitto.

*-f, --force*::
  Sovrascrivi le regole live in conflitto (*load*).

*-n, --no-clobber*::
  Salta le modifiche in conflitto.

*--dry-run*::
  Mostra le azioni senza applicarle.

*load -c/--compact*::
  Raggruppa le istruzioni corrispondenti in insiemi nft.

*unload -f/--force*::
  Spezza le regole compatte residue e rimuove gli atomi corrispondenti.

== Linguaggio di config

Una direttiva per riga. Le righe vuote sono ignorate. *#* inizia un
commento (salvo tra virgolette). Un commento sulla stessa riga di una
istruzione NAT o filtro è copiato nel commento nft dopo il tag di
proprietà. Il primo token è la direttiva; nomi e parole chiave non
distinguono maiuscole/minuscole. Il contesto vale fino alla direttiva
di contesto successiva. Non c'è sintassi a blocchi.

=== Contesto

*table* _NOME_ [_FAMIGLIA_]::
  Tabella di destinazione (predefinita *nftconf*). Famiglia *ip*
  (predefinita), *ip6*, *inet*, *arp*, *bridge*, *netdev*.

*interface* _IFACE_...::
  Confronta *iifname*; risolve anche IPv4 da quelle NIC finché non c'è
  *address*. Una regola per interfaccia.

*address* _ADDR_...::
  Confronta l'indirizzo di destinazione (*ip daddr*). Sovrascrive la
  risoluzione delle interfacce.

*dest address* / *dest interface*::
  Lato interno/VIP predefinito per `nat … to PORT`. *destination* è
  un alias di *dest*.

*priority* _NOME_|_NUMERO_::
  Priorità dell'hook INPUT. Gli hook NAT ignorano questo.

*shield* *on*|*off*::
  Allow-list INPUT a scarto predefinito per l'ambito interfaccia/indirizzo
  corrente. *on* da solo non apre porte applicative.

*include* _GLOB_::
  Include file (relativi al file includente); eredita una copia del contesto.

=== Porte (tcp / udp / sctp / dccp)

Dopo un protocollo con porte: una porta, un intervallo inclusivo, o un
elenco (spazi e/o virgole). Un solo elemento è uno scalare/intervallo;
due o più diventano un insieme anonimo nftables.

----
allow incoming tcp 22
allow incoming tcp 8000-8080
allow incoming tcp 80 443 1080 8000-8080
deny incoming tcp 33
allow outgoing ip 10.0.0.0/8 tcp 443
nat tcp 80 443 8000-8080 to 10.0.0.50
----

Porte 0–65535; *HIGH* ≥ *LOW*. Prefisso opzionale *ADDR:PORT* (o
*[IPv6]:PORT*). Altrimenti *address* / *interface* forniscono *ip daddr*.

Gli elenchi valgono per *allow* / *deny* / *whitelist* / *blacklist* e
per *nat* / *dnat* / *snat* / *masquerade* / *redirect* (prima di *to*),
non per *icmp* / *ct*.

=== NAT e filtro

*nat* / *dnat* / *snat* _PROTO_ _PORT_... *to* _DEST_, *masquerade*,
*redirect*. Il NAT non apre *INPUT*.

*allow incoming* / *deny incoming* (alias *whitelist* / *blacklist*)
si applicano a INPUT. *allow outgoing ip CIDR* [*PROTO* [_PORT_...]]
si applica a OUTPUT; omettere proto/porte equivale a tutto il traffico
verso quel CIDR.

Una *porta singola* è confrontata prima di un *intervallo*; alla stessa
specificità *allow* vince su *deny*.

Con *shield on* la policy in ingresso entra nella catena shield.

Tutto dopo *reject … with* è passato a nftables (*tcp reset*, …).

Vedere *guide.md* e `info nftconf`.

== File
