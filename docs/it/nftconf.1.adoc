== Nome

nftconf - configurazione nftables dichiarativa con riconciliazione live

== Sintassi

*nftconf* [_GLOBAL_]... _CMD_ [_OPTION_]... [_FILE_]...

== Descrizione

*nftconf* legge un piccolo linguaggio dichiarativo e lo riconcilia con il
ruleset *nftables*(8) attivo. Ogni regola logica ha un commento di proprietà.

Il NAT agisce su prerouting/output/postrouting e *non* apre *INPUT*.
Le porte consegnate all'host richiedono *whitelist*/*accept* esplicito.

== Comandi

*load* _FILE_::
  Reconcile _FILE_ against the live ruleset. One statement becomes one
  nft rule. *-c, --compact* packs matching allow/deny into nft sets.

*unload* _FILE_::
  Remove a live rule only when the whole statement matches.
  *-f, --force* splits a leftover compacted rule and removes as many
  atoms as possible.

*status* _FILE_::
  Show drift between desired and live rules.

*check* _FILE_::
  Parse and print resolved nft rules.

*show* _FILE_::
  Per-statement status (*on*, *N/M*, *---*, *xxx*).

*daemon* _FILE_::
  Watch _FILE_ (and includes); reload on change.
  Default pidfile */run/nftconf.pid*; a second instance refuses to start.

*stop*::
  Stop the daemon via the pidfile (*--pid*).

*convert* _FILE_...::
  Write consolidated *nftables.d/\*.nft*.

*help*::
  Show usage.

== Opzioni globali

*-v, --verbose*::
  Debug logging (repeatable).

*-q, --quiet*::
  Errors only.

*-h, --help*::
  Show help.

*--version*::
  Print version and exit.

== Politica di conflitto

(default)::
  Abort if existing nft settings conflict.

*-f, --force*::
  Overwrite conflicting live rules (*load*).

*-n, --no-clobber*::
  Skip conflicting changes.

*--dry-run*::
  Show actions without applying.

*load -c/--compact*::
  Pack matching statements into nft sets.

*unload -f/--force*::
  Split leftover compacted rules and remove matching atoms.

== Linguaggio di config

Una direttiva per riga. Le righe vuote sono ignorate. *#* inizia un
commento (salvo tra virgolette). Il primo token è la direttiva; nomi e
parole chiave non distinguono maiuscole/minuscole. Il contesto vale fino
alla direttiva di contesto successiva.

=== Contesto

*table*, *interface*, *address*, *dest address* / *dest interface*,
*priority*, *shield on|off*, *include*.

=== Porte (tcp / udp / sctp / dccp)

Dopo un protocollo con porte: una porta, un intervallo inclusivo, o un
elenco (spazi e/o virgole). Un solo elemento è uno scalare/intervallo;
due o più diventano un insieme anonimo nftables.

----
allow incoming tcp 22
allow incoming tcp 8000-8080
allow incoming tcp 80 443 1080 8000-8080
deny incoming tcp 33
allow outgoing ip 10.0.0.0/8 tcp 443
nat tcp 80 443 8000-8080 to 10.0.0.50
----

Porte 0–65535; *HIGH* ≥ *LOW*. Prefisso opzionale *ADDR:PORT* (o
*[IPv6]:PORT*). Altrimenti *address* / *interface* forniscono *ip daddr*.
Gli elenchi valgono per filtro e NAT (prima di *to*), non per
*icmp* / *ct*.

=== NAT e filtro

*nat* / *dnat* / *snat* _PROTO_ _PORT_... *to* _DEST_, *masquerade*,
*redirect*. Il NAT non apre *INPUT*.

*whitelist* / *allow* sono alias di *accept*. Con *shield on* entrano
nella catena shield. Tutto dopo *reject … with* è passato a nftables
(*tcp reset*, …).

Vedere *guide.md* e `info nftconf`.

== File

*/run/nftconf.pid*::
  Default daemon pidfile.

*nftables.d/\*.nft*::
  Default *convert* output directory.

== Stato di uscita

*0*::
  Success.

*1*::
  Config/conflict/runtime error.

*2*::
  Usage error.
