== 名前

nftconf - 宣言的 nftables 設定とライブ調整

== 書式

*nftconf* [_GLOBAL_]... _CMD_ [_OPTION_]... [_FILE_]...

== 説明

*nftconf* は簡潔な宣言的設定を読み、稼働中の *nftables*(8) ルールセットと突合します。
各論理ルールには所有コメントが付き、*load* / *unload* / *daemon* は当該設定のルールだけを変更します。

NAT は prerouting/output/postrouting に作用し、*INPUT* は開きません。
ホスト配送が必要なポートには明示的な *whitelist*/*accept*（任意で *shield on*）が必要です。

== コマンド

*load* _FILE_::
  Reconcile _FILE_ against the live ruleset.

*unload* _FILE_::
  Remove live rules owned by _FILE_.

*status* _FILE_::
  Show drift between desired and live rules.

*check* / *show* _FILE_::
  Parse and print resolved rules (no apply).

*daemon* _FILE_::
  Watch _FILE_ (and includes); reload on change.
  Default pidfile */run/nftconf.pid*; a second instance refuses to start.

*stop*::
  Stop the daemon via the pidfile (*--pid*).

*convert* _FILE_...::
  Write consolidated *nftables.d/\*.nft*.

*help*::
  Show usage.

== グローバルオプション

*-v, --verbose*::
  Debug logging (repeatable).

*-q, --quiet*::
  Errors only.

*-h, --help*::
  Show help.

*--version*::
  Print version and exit.

== 競合ポリシー

(default)::
  Abort if existing nft settings conflict.

*-f, --force*::
  Overwrite (load) or remove owned rules anyway (unload).

*-n, --no-clobber*::
  Skip conflicting changes.

*--dry-run*::
  Show actions without applying.

== 設定言語

One directive per line. Blank lines ignored. *#* starts a comment (unless
quoted). The first token is the directive; names and keywords are
case-insensitive. Context lasts until the next context directive.

=== Context

*table*, *interface*, *address*, *dest address* / *dest interface*,
*priority*, *shield on|off*, *include*.

=== Ports (tcp / udp / sctp / dccp)

After a portful protocol: a port, an inclusive range, or a list (spaces
and/or commas). One atom is a scalar/range; two or more become an
nftables anonymous set.

----
whitelist tcp 22
whitelist tcp 8000-8080
whitelist tcp 80 443 1080 8000-8080
whitelist tcp 80,443,1080,8000-8080
nat tcp 80 443 8000-8080 to 10.0.0.50
----

Ports 0–65535; *HIGH* ≥ *LOW*. Optional *ADDR:PORT* (or *[IPv6]:PORT*)
prefix. Otherwise *address* / *interface* supply *ip daddr*. Lists apply
to filter and NAT (before *to*), not *icmp* / *ct*.

=== NAT and filter

*nat* / *dnat* / *snat* _PROTO_ _PORT_... *to* _DEST_, *masquerade*,
*redirect*. NAT does not open *INPUT*.

*whitelist* / *allow* alias *accept*. With *shield on* they join the
shield chain. Everything after *reject … with* is passed to nftables
(*tcp reset*, …).

See *guide.md* and `info nftconf`.
