== Name

nftconf - declarative nftables configuration with live reconcile

== Synopsis

*nftconf* [_GLOBAL_]... _CMD_ [_OPTION_]... [_FILE_]...

== Description

*nftconf* reads a small declarative config language and reconciles it against
the live *nftables*(8) ruleset. Each logical rule is tagged with an ownership
comment so later *load*, *unload*, and *daemon* runs can add, update, or remove
only rules that belong to that config file.

NAT rules are applied on prerouting/output/postrouting hooks and *do not* open
*INPUT*. Ports that must be delivered to the host need an explicit
*whitelist*/*accept* (and optionally *shield on*).

== Commands

*load* _FILE_::
  Reconcile _FILE_ against the live ruleset.

*unload* _FILE_::
  Remove live rules owned by _FILE_.

*status* _FILE_::
  Show drift between desired and live rules.

*check* / *show* _FILE_::
  Parse and print resolved rules (no apply).

*daemon* _FILE_::
  Watch _FILE_ (and includes) with inotify; reload on change.
  Uses a pidfile (default */run/nftconf.pid*) so a second instance refuses to start.

*stop*::
  Stop the daemon via the pidfile (*--pid*).

*convert* _FILE_...::
  Write consolidated *nftables.d/\*.nft* (defines + port sets).

*help*::
  Show usage.

== Global options

*-v, --verbose*::
  Debug logging (repeatable).

*-q, --quiet*::
  Errors only.

*-h, --help*::
  Show help.

*--version*::
  Print version and exit.

== Conflict policy

Applies to *load*, *unload*, *daemon*, and *convert*:

(default)::
  Abort if existing nft settings conflict.

*-f, --force*::
  Overwrite (load) or remove owned rules anyway (unload).

*-n, --no-clobber*::
  Skip conflicting changes; leave existing settings alone.

*--dry-run*::
  Show actions without applying.

== Configuration language

A config file is one directive per line. Blank lines are ignored.
*#* starts a comment (unless inside quotes). The first token is the
directive; names and keywords are case-insensitive. Context applies to
every following rule until the next context directive. There is no block
syntax.

=== Context

*table* _NAME_ [_FAMILY_]::
  Target table (default *nftconf*). Family *ip* (default), *ip6*, *inet*,
  *arp*, *bridge*, *netdev*.

*interface* _IFACE_...::
  Match *iifname*; also resolve IPv4 from those NICs until *address* is set.
  One rule is emitted per interface.

*address* _ADDR_...::
  Destination-address match (*ip daddr*). Overrides interface resolution.

*dest address* _ADDR_... / *dest interface* _IFACE_...::
  Default internal/VIP side for `nat … to PORT`. *destination* is an alias
  of *dest*.

*priority* _NAME_|_NUMBER_::
  INPUT hook priority (*raw*, *mangle*, *dstnat*, *filter*, *security*,
  *srcnat*, or an integer). NAT hooks ignore this.

*shield* *on*|*off*::
  Drop-default INPUT allow-list for the current interface/address scope.
  *on* does not open application ports by itself.

*include* _GLOB_::
  Include files (relative to the including file); inherits a copy of the
  current context.

=== Port specs (tcp / udp / sctp / dccp)

After a portful protocol, write a port, an inclusive range, or a list.
Items may be separated by spaces and/or commas. A single atom is emitted
as a scalar or range; two or more become an nftables anonymous set.

----
whitelist tcp 22
whitelist tcp 8000-8080
whitelist tcp 80 443 1080 8000-8080
whitelist tcp 80,443,1080,8000-8080
whitelist tcp 192.0.2.10:80 443
nat tcp 80 443 8000-8080 to 10.0.0.50
----

Ports are 0–65535; *HIGH* must be ≥ *LOW*. An optional *ADDR:PORT* (or
*[IPv6]:PORT*) prefixes the list; following bare ports share that
address. Otherwise *address* / *interface* supply *ip daddr*.

Lists are accepted on *whitelist* / *accept* / *allow* / *drop* /
*reject* and on *nat* / *dnat* / *snat* / *masquerade* / *redirect*
(before *to*). Not used for *icmp* / *ct*.

The token after *to* is one destination: *ADDR* (keep source ports),
*PORT* (use *dest address*), or *ADDR:PORT*.

=== NAT

*nat* / *dnat* / *snat* _PROTO_ _PORT_... *to* _DEST_, *masquerade*
[_PROTO_ [_PORT_...]], *redirect* _PROTO_ _PORT_... *to* _PORT_.

NAT uses prerouting/output/postrouting and *does not* open *INPUT*.

=== Filter

*whitelist* / *allow* are aliases of *accept*. With *shield on* they join
the shield chain (established/related and ICMP are allowed, then
user ports, then *drop*).

----
shield on
whitelist tcp 22
whitelist tcp 80 443 1080 8000-8080
accept icmp
reject tcp 25 587 with tcp reset
drop
----

*accept* with no match is a catch-all; *accept tcp* matches any TCP.
Everything after *reject … with* is passed to nftables (*tcp reset*, …).

See *guide.md* and `info nftconf` for the full language.
