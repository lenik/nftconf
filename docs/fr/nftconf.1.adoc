== Nom

nftconf - configuration nftables déclarative avec réconciliation live

== Synopsis

*nftconf* [_GLOBAL_]... _CMD_ [_OPTION_]... [_FICHIER_]...

== Description

*nftconf* lit un petit langage de configuration déclaratif et le réconcilie
avec le jeu de règles *nftables*(8) actif. Chaque règle logique porte un
commentaire de propriété pour que *load*, *unload* et *daemon* n'ajoutent ou
n'enlèvent que les règles appartenant à ce fichier.

Le NAT s'applique en prerouting/output/postrouting et *n'ouvre pas* *INPUT*.
Les ports livrés à l'hôte nécessitent un *whitelist*/*accept* explicite
(optionnellement *shield on*).

== Commandes

*load* _FICHIER_::
  Réconcilie _FICHIER_ avec le jeu live. Une instruction devient une
  règle nft. *-c, --compact* regroupe les allow/deny correspondants
  en ensembles nft.

*unload* _FICHIER_::
  Retire une règle live seulement si l'instruction correspond entièrement.
  *-f, --force* scinde une règle compactée restante et retire autant
  d'atomes que possible.

*status* _FICHIER_::
  Affiche l'écart entre désiré et live.

*check* _FICHIER_::
  Analyse et affiche les règles nft résolues.

*show* _FICHIER_::
  État par instruction, colonne de largeur 8 : *on* (entièrement live),
  *N/M* (partiel), *---* (non chargé), *xxx* (erreur de syntaxe).

*daemon* _FICHIER_::
  Surveille _FICHIER_ (et includes) et recharge aux changements.
  Pidfile par défaut */run/nftconf.pid* ; une seconde instance est refusée.

*stop*::
  Arrête le démon via le pidfile (*--pid*).

*convert* _FICHIER_...::
  Écrit des *nftables.d/\*.nft* consolidés.

*help*::
  Affiche l'aide.

== Options globales

*-v, --verbose*::
  Journal de débogage (répétable).

*-q, --quiet*::
  Erreurs seulement.

*-h, --help*::
  Afficher l'aide.

*--version*::
  Afficher la version et quitter.

== Politique de conflit

S'applique à *load*, *daemon* et *convert* :

(défaut)::
  Abandon en cas de conflit avec les réglages nft existants.

*-f, --force*::
  Écraser les règles live en conflit (*load*).

*-n, --no-clobber*::
  Ignorer les changements en conflit.

*--dry-run*::
  Afficher sans appliquer.

*load -c/--compact*::
  Regrouper les instructions correspondantes en ensembles nft.

*unload -f/--force*::
  Scinder une règle compactée restante et retirer les atomes correspondants.

== Langage de config

Une directive par ligne. Les lignes vides sont ignorées. *#* commence un
commentaire (sauf entre guillemets). Un commentaire sur la même ligne
qu'une instruction NAT ou filtre est copié dans le commentaire nft après
l'étiquette de propriété. Le premier jeton est la directive ;
noms et mots-clés sont insensibles à la casse. Un contexte s'applique
jusqu'à la directive de contexte suivante.

=== Contexte

*table*, *interface*, *address*, *dest address* / *dest interface*,
*priority*, *shield on|off*, *include*.

=== Ports (tcp / udp / sctp / dccp)

Après un protocole à ports : un port, une plage inclusive, ou une liste
(espaces et/ou virgules). Un seul élément est émis comme scalaire/plage ;
deux ou plus comme ensemble anonyme nftables.

----
allow incoming tcp 22
allow incoming tcp 8000-8080
allow incoming tcp 80 443 1080 8000-8080
deny incoming tcp 33
allow outgoing ip 10.0.0.0/8 tcp 443
nat tcp 80 443 8000-8080 to 10.0.0.50
----

Ports 0–65535 ; *HIGH* ≥ *LOW*. Préfixe optionnel *ADDR:PORT* (ou
*[IPv6]:PORT*). Sinon *address* / *interface* fournissent *ip daddr*.
Les listes s'appliquent aux filtres et au NAT (avant *to*), pas à
*icmp* / *ct*.

=== NAT et filtre

*nat* / *dnat* / *snat* _PROTO_ _PORT_... *to* _DEST_, *masquerade*,
*redirect*. Le NAT n'ouvre pas *INPUT*.

*whitelist* / *allow* sont des alias de *accept*. Avec *shield on*, ils
rejoignent la chaîne bouclier. Tout ce qui suit *reject … with* est
passé à nftables (*tcp reset*, …).

Voir *guide.md* et `info nftconf`.

== Fichiers

*/run/nftconf.pid*::
  Pidfile par défaut du démon.

*nftables.d/\*.nft*::
  Sortie par défaut de *convert*.

== Code de sortie

*0*::
  Succès.

*1*::
  Erreur de config/conflit/exécution.

*2*::
  Erreur d'utilisation.
