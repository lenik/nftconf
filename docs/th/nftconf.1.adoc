== ชื่อ

nftconf - การตั้งค่า nftables แบบประกาศพร้อมปรับกับกฎสด

== รูปแบบ

*nftconf* [_ส่วนกลาง_]... _CMD_ [_ตัวเลือก_]... [_FILE_]...

== คำอธิบาย

*nftconf* อ่านภาษากำหนดค่าแบบประกาศแล้วปรับกับกฎ *nftables*(8) ที่ใช้งานอยู่
แต่ละกฎมีคอมเมนต์ความเป็นเจ้าของ เพื่อให้ *load* / *unload* / *daemon*
เปลี่ยนเฉพาะกฎของไฟล์นั้น

NAT ทำงานที่ prerouting/output/postrouting และ *ไม่* เปิด *INPUT*
พอร์ตที่ส่งถึงโฮสต์ต้องมี *allow incoming* (หรือ *whitelist* และเลือก *shield on*)

== คำสั่ง

*load* _FILE_::
  ปรับ _FILE_ กับกฎสด ค่าเริ่มต้นหนึ่งคำสั่งเป็นหนึ่งกฎ nft
  *-c, --compact* รวม allow/deny ที่เข้ากันเข้า nft set (พฤติกรรมเดิม)

*unload* _FILE_::
  ลบกฎสดเมื่อคำสั่งตรงทั้งก้อนเท่านั้น *-f, --force* แยกกฎที่ถูกบีบอัดเหลืออยู่
  และลบอะตอมให้ได้มากที่สุด (เมื่อต้นฉบับหดหรือถูกแก้)

*status* _FILE_::
  แสดงความคลาดเคลื่อนระหว่างที่ต้องการกับกฎสด

*check* _FILE_::
  วิเคราะห์และพิมพ์กฎ nft ที่คลี่แล้ว (ไม่นำไปใช้)

*show* _FILE_::
  พิมพ์แต่ละคำสั่งพร้อมคอลัมน์สถานะกว้าง 8: *on* (มีผลครบ), *N/M* (บางส่วน),
  *---* (ยังไม่โหลด), *xxx* (ผิดวากยสัมพันธ์)

*daemon* _FILE_::
  เฝ้า _FILE_ (และ include) ด้วย inotify แล้วโหลดใหม่เมื่อเปลี่ยน
  pidfile เริ่มต้น */run/nftconf.pid* อินสแตนซ์ที่สองจะถูกปฏิเสธ

*stop*::
  หยุดดีมอนผ่าน pidfile (*--pid*)

*convert* _FILE_...::
  เขียน *nftables.d/\*.nft* รวม (define และชุดพอร์ต)

*help*::
  แสดงวิธีใช้

== ตัวเลือกส่วนกลาง

*-v, --verbose*::
  บันทึกดีบัก (ซ้ำได้)

*-q, --quiet*::
  เฉพาะข้อผิดพลาด

*-h, --help*::
  แสดงวิธีใช้

*--version*::
  พิมพ์รุ่นแล้วออก

== นโยบายความขัดแย้ง

ใช้กับ *load*, *daemon* และ *convert*:

(ค่าเริ่มต้น)::
  ยกเลิกถ้าการตั้งค่า nft ที่มีอยู่ขัดแย้ง

*-f, --force*::
  เขียนทับกฎสดที่ขัดแย้ง (*load*)

*-n, --no-clobber*::
  ข้ามการเปลี่ยนแปลงที่ขัดแย้ง

*--dry-run*::
  แสดงการกระทำโดยไม่นำไปใช้

*load -c/--compact*::
  รวมคำสั่งที่เข้ากันเข้า nft set

*unload -f/--force*::
  แยกกฎที่ถูกบีบอัดเหลืออยู่และลบอะตอมที่ตรงกัน

== ภาษากำหนดค่า

หนึ่งคำสั่งต่อบรรทัด บรรทัดว่างถูกละเว้น *#* เริ่มความเห็น (ยกเว้นในอัญประกาศ)
ความเห็นบรรทัดเดียวกับคำสั่ง NAT หรือตัวกรองจะถูกคัดลอกไปยังคอมเมนต์กฎ nft
หลังแท็กเจ้าของ โทเคนแรกคือชื่อคำสั่ง ชื่อและคำสำคัญไม่แยกตัวพิมพ์
บริบทใช้ได้จนถึงคำสั่งบริบทถัดไป ไม่มีวากยสัมพันธ์แบบบล็อก

=== บริบท

*table* _ชื่อ_ [_ตระกูล_]::
  ตารางเป้าหมาย (ค่าเริ่มต้น *nftconf*) ตระกูล *ip* (ค่าเริ่มต้น), *ip6*,
  *inet*, *arp*, *bridge*, *netdev*

*interface* _IFACE_...::
  จับคู่ *iifname* และแปลง IPv4 จาก NIC เหล่านั้นจนกว่าจะมี *address*
  หนึ่งกฎต่ออินเทอร์เฟซ

*address* _ADDR_...::
  จับคู่ที่อยู่ปลายทาง (*ip daddr*) ทับการแปลงจากอินเทอร์เฟซ

*dest address* / *dest interface*::
  ด้านภายใน/VIP เริ่มต้นของ `nat … to PORT` *destination* เป็นนามแฝงของ *dest*

*priority* _ชื่อ_|_ตัวเลข_::
  ลำดับความสำคัญของฮุก INPUT ฮุก NAT ไม่ใช้ค่านี้

*shield* *on*|*off*::
  รายการอนุญาต INPUT ที่ทิ้งเป็นค่าเริ่มต้นสำหรับขอบเขตอินเทอร์เฟซ/ที่อยู่ปัจจุบัน
  *on* เดี่ยวไม่เปิดพอร์ตแอป

*include* _GLOB_::
  รวมไฟล์ (สัมพัทธ์กับไฟล์ที่รวม) สืบทอดสำเนาบริบทปัจจุบัน

=== พอร์ต (tcp / udp / sctp / dccp)

หลังโปรโตคอลที่มีพอร์ต: พอร์ต ช่วงปิด หรือรายการ (ช่องว่างและ/หรือจุลภาค)
หนึ่งรายการเป็นสเกลาร์/ช่วง สองรายการขึ้นไปเป็นเซ็ตนิรนาม nftables

----
allow incoming tcp 22
allow incoming tcp 8000-8080
allow incoming tcp 80 443 1080 8000-8080
deny incoming tcp 33
allow outgoing ip 10.0.0.0/8 tcp 443
nat tcp 80 443 8000-8080 to 10.0.0.50
----

พอร์ต 0–65535; *HIGH* ≥ *LOW* คำนำหน้า *ADDR:PORT* (หรือ *[IPv6]:PORT*) ได้
มิฉะนั้น *address* / *interface* ให้ *ip daddr*

รายการใช้ได้กับ *allow* / *deny* / *whitelist* / *blacklist* และ
*nat* / *dnat* / *snat* / *masquerade* / *redirect* (ก่อน *to*) ไม่ใช้กับ
*icmp* / *ct*

=== NAT และตัวกรอง

*nat* / *dnat* / *snat* _PROTO_ _PORT_... *to* _DEST_, *masquerade*,
*redirect* NAT ไม่เปิด *INPUT*

*allow incoming* / *deny incoming* (นามแฝง *whitelist* / *blacklist*)
ใช้กับ INPUT *allow outgoing ip CIDR* [*PROTO* [_PORT_...]] ใช้กับ OUTPUT
ถ้าไม่ระบุโปรโตคอล/พอร์ตจะจับจราจรทั้งหมดไปยัง CIDR นั้น

*พอร์ตเดี่ยว* จับก่อน *ช่วง*; ความจำเพาะเท่ากัน *allow* ชนะ *deny*

เมื่อ *shield on* นโยบายขาเข้าเข้าสู่โซ่เกราะ

ทุกอย่างหลัง *reject … with* ส่งให้ nftables (*tcp reset* ฯลฯ)

ดู *guide.md* และ `info nftconf`
