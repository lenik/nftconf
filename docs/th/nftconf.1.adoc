== ชื่อ

nftconf - การตั้งค่า nftables แบบประกาศพร้อม synchronize สด

== รูปแบบ

*nftconf* [_GLOBAL_]... _CMD_ [_OPTION_]... [_FILE_]...

== คำอธิบาย

*nftconf* อ่านภาษากำหนดค่าแบบประกาศแล้วปรับกับกฎ *nftables*(8) ที่ใช้งานอยู่
แต่ละกฎมีคอมเมนต์ความเป็นเจ้าของ

NAT ทำงานที่ prerouting/output/postrouting และ *ไม่* เปิด *INPUT*
พอร์ตที่ส่งถึงโฮสต์ต้องมี *whitelist*/*accept* ชัดเจน

== คำสั่ง

*load* _FILE_::
  Reconcile _FILE_ against the live ruleset.

*unload* _FILE_::
  Remove live rules owned by _FILE_.

*status* _FILE_::
  Show drift between desired and live rules.

*check* / *show* _FILE_::
  Parse and print resolved rules (no apply).

*daemon* _FILE_::
  Watch _FILE_ (and includes); reload on change.
  Default pidfile */run/nftconf.pid*; a second instance refuses to start.

*stop*::
  Stop the daemon via the pidfile (*--pid*).

*convert* _FILE_...::
  Write consolidated *nftables.d/\*.nft*.

*help*::
  Show usage.

== ตัวเลือกทั่วไป

*-v, --verbose*::
  Debug logging (repeatable).

*-q, --quiet*::
  Errors only.

*-h, --help*::
  Show help.

*--version*::
  Print version and exit.

== นโยบายความขัดแย้ง

(default)::
  Abort if existing nft settings conflict.

*-f, --force*::
  Overwrite (load) or remove owned rules anyway (unload).

*-n, --no-clobber*::
  Skip conflicting changes.

*--dry-run*::
  Show actions without applying.

== ภาษาคอนฟิก

คำสั่งละบรรทัด บรรทัดว่างถูกละเว้น *#* เริ่มหมายเหตุ (ยกเว้นในเครื่องหมายคำพูด)
โทเคนแรกคือคำสั่ง ชื่อและคำสำคัญไม่แยกตัวพิมพ์ บริบทใช้ได้จนกว่าจะมีคำสั่งบริบทถัดไป

=== บริบท

*table*, *interface*, *address*, *dest address* / *dest interface*,
*priority*, *shield on|off*, *include*.

=== พอร์ต (tcp / udp / sctp / dccp)

หลังโปรโตคอลที่มีพอร์ต: พอร์ตเดียว, ช่วงรวมปลาย, หรือรายการ (ช่องว่างและ/หรือจุลภาค)
หนึ่งรายการเป็นสเกลาร์/ช่วง สองรายการขึ้นไปเป็นเซตนามแฝง nftables

----
whitelist tcp 22
whitelist tcp 8000-8080
whitelist tcp 80 443 1080 8000-8080
whitelist tcp 80,443,1080,8000-8080
nat tcp 80 443 8000-8080 to 10.0.0.50
----

พอร์ต 0–65535; *HIGH* ≥ *LOW* คำนำหน้า *ADDR:PORT* (หรือ *[IPv6]:PORT*) ได้
มิฉะนั้น *address* / *interface* ให้ *ip daddr* รายการใช้กับ filter และ NAT
(ก่อน *to*) ไม่ใช้กับ *icmp* / *ct*

=== NAT และตัวกรอง

*nat* / *dnat* / *snat* _PROTO_ _PORT_... *to* _DEST_, *masquerade*,
*redirect*. NAT ไม่เปิด *INPUT*

*whitelist* / *allow* เป็นนามแฝงของ *accept* เมื่อ *shield on* จะเข้าสู่สาย
shield ทุกโทเคนหลัง *reject … with* ส่งให้ nftables (*tcp reset*, …)

ดู *guide.md* และ `info nftconf`

== ไฟล์

== สถานะออก

*1*::
  Config/conflict/runtime error.

*2*::
  Usage error.
