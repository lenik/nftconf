== Tên

nftconf - cấu hình nftables khai báo với đối soát trực tiếp

== Tóm tắt

*nftconf* [_GLOBAL_]... _CMD_ [_OPTION_]... [_FILE_]...

== Mô tả

*nftconf* đọc ngôn ngữ cấu hình khai báo ngắn và đối soát với ruleset
*nftables*(8) đang chạy. Mỗi quy tắc logic có chú thích sở hữu.

NAT áp dụng trên prerouting/output/postrouting và *không* mở *INPUT*.
Cổng giao cho máy chủ cần *whitelist*/*accept* rõ ràng.

== Lệnh

*load* _FILE_::
  Reconcile _FILE_ against the live ruleset.

*unload* _FILE_::
  Remove live rules owned by _FILE_.

*status* _FILE_::
  Show drift between desired and live rules.

*check* / *show* _FILE_::
  Parse and print resolved rules (no apply).

*daemon* _FILE_::
  Watch _FILE_ (and includes); reload on change.
  Default pidfile */run/nftconf.pid*; a second instance refuses to start.

*stop*::
  Stop the daemon via the pidfile (*--pid*).

*convert* _FILE_...::
  Write consolidated *nftables.d/\*.nft*.

*help*::
  Show usage.

== Tùy chọn toàn cục

*-v, --verbose*::
  Debug logging (repeatable).

*-q, --quiet*::
  Errors only.

*-h, --help*::
  Show help.

*--version*::
  Print version and exit.

== Chính sách xung đột

(default)::
  Abort if existing nft settings conflict.

*-f, --force*::
  Overwrite (load) or remove owned rules anyway (unload).

*-n, --no-clobber*::
  Skip conflicting changes.

*--dry-run*::
  Show actions without applying.

== Ngôn ngữ cấu hình

Một chỉ thị mỗi dòng. Dòng trống bị bỏ qua. *#* bắt đầu chú thích (trừ
trong ngoặc kép). Token đầu là chỉ thị; tên và từ khóa không phân biệt
hoa thường. Ngữ cảnh giữ đến chỉ thị ngữ cảnh tiếp theo.

=== Ngữ cảnh

*table*, *interface*, *address*, *dest address* / *dest interface*,
*priority*, *shield on|off*, *include*.

=== Cổng (tcp / udp / sctp / dccp)

Sau giao thức có cổng: một cổng, khoảng inclusive, hoặc danh sách
(khoảng trắng và/hoặc dấu phẩy). Một phần tử thành vô hướng/khoảng; hai
trở lên thành tập ẩn danh nftables.

----
whitelist tcp 22
whitelist tcp 8000-8080
whitelist tcp 80 443 1080 8000-8080
whitelist tcp 80,443,1080,8000-8080
nat tcp 80 443 8000-8080 to 10.0.0.50
----

Cổng 0–65535; *HIGH* ≥ *LOW*. Tiền tố tùy chọn *ADDR:PORT* (hoặc
*[IPv6]:PORT*). Không thì *address* / *interface* cung cấp *ip daddr*.
Danh sách dùng cho filter và NAT (trước *to*), không dùng cho
*icmp* / *ct*.

=== NAT và filter

*nat* / *dnat* / *snat* _PROTO_ _PORT_... *to* _DEST_, *masquerade*,
*redirect*. NAT không mở *INPUT*.

*whitelist* / *allow* là bí danh của *accept*. Với *shield on* chúng vào
chuỗi shield. Mọi token sau *reject … with* được đưa cho nftables
(*tcp reset*, …).

Xem *guide.md* và `info nftconf`.

== Tệp

*/run/nftconf.pid*::
  Default daemon pidfile.

*nftables.d/\*.nft*::
  Default *convert* output directory.

== Mã thoát

*0*::
  Success.

*1*::
  Config/conflict/runtime error.

*2*::
  Usage error.
