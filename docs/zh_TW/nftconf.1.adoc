== 名稱

nftconf - 宣告式 nftables 設定與即時對帳

== 語法

*nftconf* [_全域選項_]... _命令_ [_選項_]... [_檔案_]...

== 描述

*nftconf* 讀取簡潔的宣告式設定，並與執行中的 *nftables*(8) 規則集對帳。
每條邏輯規則帶有所有權註解，便於後續 *load*、*unload*、*daemon* 只增刪屬於該設定檔的規則。

NAT 作用在 prerouting/output/postrouting，*不會* 自動開放 *INPUT*。
需要本機投遞的埠必須明確 *whitelist*/*accept*（可選 *shield on*）。

== 命令

*load* _檔案_::
  將 _檔案_ 與活動規則集對帳。預設一條 statement 對應一條 nft 規則。
  *-c, --compact* 將匹配的 allow/deny 打包進 nft 集合（舊行為）。

*unload* _檔案_::
  僅在整條 statement 完全匹配時移除活動規則。*-f, --force*
  在整體不匹配時拆散殘餘的打包規則，盡可能多地移除原子。

*status* _檔案_::
  顯示期望與活動規則之間的差異。

*check* _檔案_::
  解析並印出展開後的 nft 規則。

*show* _檔案_::
  每條 statement 左側寬 8 的狀態欄：*on*（完全有效）、*N/M*（部分有效）、
  *---*（未載入）、*xxx*（語法錯誤）。

*daemon* _檔案_::
  監視 _檔案_（及 include），變更時重新載入。
  預設使用 pidfile */run/nftconf.pid*，第二實例會拒絕啟動。

*stop*::
  透過 pidfile（*--pid*）停止守護行程。

*convert* _檔案_...::
  寫出彙總的 *nftables.d/\*.nft*。

*help*::
  顯示用法。

== 全域選項

*-v, --verbose*::
  除錯日誌（可重複）。

*-q, --quiet*::
  僅錯誤。

*-h, --help*::
  顯示說明。

*--version*::
  輸出版本並結束。

== 衝突策略

適用於 *load*、*daemon*、*convert*：

（預設）::
  與現有 nft 設定衝突則中止。

*-f, --force*::
  覆寫衝突的活動規則（*load*）。

*-n, --no-clobber*::
  略過衝突變更。

*--dry-run*::
  只顯示動作，不套用。

*load -c/--compact*::
  將匹配的 statement 打包進 nft 集合。

*unload -f/--force*::
  拆散殘餘的打包規則並移除匹配的原子。

== 設定語言

設定檔每行一條指令。空行忽略。*#* 起註解（引號內除外）。與 NAT 或
過濾 statement 同一行的註解會複製到 nft 規則 comment 中（所有權標籤之後）。
首個詞元為指令名，指令與關鍵字不分大小寫。上下文對其後規則一直有效，
直到下一條上下文指令。沒有區塊語法。

=== 上下文

*table* _名稱_ [_族_]::
  目標表（預設 *nftconf*）。族為 *ip*（預設）、*ip6*、*inet*、*arp*、
  *bridge*、*netdev*。

*interface* _網卡_...::
  匹配 *iifname*；並解析這些網卡的 IPv4，直到出現 *address*。每個網卡產生一條規則。

*address* _位址_...::
  目的位址匹配（*ip daddr*），覆蓋網卡解析。

*dest address* / *dest interface*::
  `nat … to PORT` 的預設內網/VIP 側。*destination* 是 *dest* 的別名。

*priority* _名_|_數_::
  INPUT 掛鉤優先順序。NAT 掛鉤不受此影響。

*shield* *on*|*off*::
  目前網卡/位址作用域的預設丟棄 INPUT 白名單。*on* 本身不會開放應用埠。

*include* _GLOB_::
  包含檔案（相對包含者所在目錄）；繼承目前上下文的副本。

=== 埠（tcp / udp / sctp / dccp）

埠協定之後寫：單一埠、閉區間、或列表（空白及/或逗號分隔）。
單項產生為純量或區間；兩項以上產生為 nftables 匿名集合。

----
allow incoming tcp 22
allow incoming tcp 8000-8080
allow incoming tcp 80 443 1080 8000-8080
deny incoming tcp 33
allow outgoing ip 10.0.0.0/8 tcp 443
nat tcp 80 443 8000-8080 to 10.0.0.50
----

埠範圍 0–65535；*HIGH* 必須 ≥ *LOW*。可選 *ADDR:PORT*（或 *[IPv6]:PORT*）
作為列表前綴。否則由 *address* / *interface* 提供 *ip daddr*。

列表可用於 *whitelist* / *accept* / *allow* / *drop* / *reject*，以及
*nat* / *dnat* / *snat* / *masquerade* / *redirect*（在 *to* 之前）。
不用於 *icmp* / *ct*。

=== NAT 與過濾

*nat* / *dnat* / *snat* _協定_ _埠_... *to* _目的_，*masquerade*，
*redirect*。NAT *不會* 開放 *INPUT*。

*whitelist* / *allow* 等同 *accept*。*shield on* 時進入盾牌鏈。
*reject … with* 之後的全部詞元交給 nftables（如 *tcp reset*）。

詳見 *guide.md* 與 `info nftconf`。
